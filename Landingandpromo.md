App Store Description (≈ 2,500–3,000 characters)
Trap Tracker helps you place, remember, and manage traps in the field — fast, accurately, and reliably — even when GPS isn’t perfect.
If you’ve ever set a trap, baited it carefully, and returned days or weeks later wondering “where did I put that?”, Trap Tracker was built for you.
📸 The Fastest Way (Recommended)
Take a photo in the field. If your camera has location enabled, Trap Tracker automatically places the trap on the map using the photo’s GPS data.
Tip: Enable Location → While Using App → Precise Location for the best experience.
No typing coordinates. No guessing. Just take the photo and move on.

📍 Manual Placement (When GPS Isn’t Available)
If a photo doesn’t include GPS — or if you want to place traps ahead of time — you can place a trap manually.
How manual placement works:
	•	Long-press anywhere on the map
	•	Adjust the pin if needed
	•	Save the trap
	•	Add a photo now or later
Photos added later never change the trap’s location unless you explicitly choose to use photo GPS.
You stay in control.

🖼️ Add Photos Anytime
Photos are optional, but powerful.
You can:
	•	Take Photo — capture a new image in the field
	•	Upload Photo — attach an existing image
Photos help with:
	•	Visual memory
	•	Site context
	•	Faster identification when checking traps

🎨 Clear Status at a Glance
Trap Tracker uses simple color-coding so you know what needs attention instantly:
	•	Green — Good / Not due yet
	•	Amber — Due soon (within 24 hours)
	•	Red — Overdue, Sprung, or Maintenance needed
After checking a trap:
	•	Good / Caught → Schedule resets, turns green
	•	Sprung → Red (needs immediate attention)
	•	Maintenance → Red (needs repair or reset)

🌐 Offline-Ready by Design
Trap Tracker works offline in the field. Your data syncs automatically when a connection is available.
No signal? No problem.

💡 Built for Real-World Use
	•	GPS is never guessed
	•	Manual placement is just as valid as photo placement
	•	Your data stays on your device
	•	You’re always in control
Trap Tracker is designed for landowners, property managers, caretakers, and anyone who wants a reliable way to manage traps without friction.

Professional Use Statement
Trap Tracker is a field documentation and location-recordkeeping tool designed to support pest-control operations, property caretaking, and land management activities.
The application provides:
	•	Accurate recording of trap placement locations
	•	Visual documentation via user-supplied photos
	•	Offline-first operation for field environments
	•	Clear status indicators for inspection and maintenance cycles
Trap Tracker does not:
	•	Track users
	•	Monitor movement
	•	Collect personal data
	•	Transmit location information externally
All data remains under the control of the user and is stored locally on the device.
Location data is applied only when explicitly provided by the user (e.g., via GPS-enabled photos or manual placement). Manual placements are never overridden without user confirmation.
Trap Tracker is intended as a recordkeeping and operational aid, not as a regulatory reporting system or enforcement tool.
