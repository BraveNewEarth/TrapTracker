# TrapTracker

**Track Every Trap. Control Every Property.**

TrapTracker is an offline-first, GPS-enabled pest control tracking app built as a React + TypeScript Progressive Web App. It is designed for property managers, homeowners, and field technicians who need to reliably track the location, status, and history of pest traps across properties without relying on cellular service.

## 🚀 Quick Start

To view the landing page locally:

1. Open `files/index.html` in your web browser
2. Or use a local server:
   ```bash
   cd files
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`
